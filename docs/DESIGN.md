# Дизайн-система

Минимализм: нейтральные тёмные поверхности, **один** акцент — охра, никаких градиентов
и цветных свечений. Всё живёт в `src/BluetoothManagerPro/Themes/`.

## Типографика

`Segoe UI Variable Text` с откатом на `Segoe UI` — на Windows 10 переменного начертания нет,
WPF подставит обычный Segoe UI, разница почти незаметна. Заголовки — `Segoe UI Variable Display`.

| Роль | Размер | Вес |
|---|---|---|
| `Title` | 20 | SemiBold |
| `Subtitle` | 15 | SemiBold |
| `Body` | 13 | Regular / SemiBold |
| `Caption` | 11 | Regular |

`TextFormattingMode="Ideal"` и `UseLayoutRounding="True"` на корне окна.

## Геометрия

Сетка 4 px. Радиусы намеренно маленькие — интерфейс должен читаться как точный, а не пухлый.

| | Значение |
|---|---|
| Радиусы | 4 (чипы) · 6 (кнопки, поля) · 10 (карточки, поповер) |
| Высота контролов | 32 (кнопка) · 34 (поле) · 38 (плашка иконки) |
| Иконки | 14 / 18 / 22, обводка 1.5–1.8 |
| Окно | 460 × 680, минимум 400 × 480 |
| Поповер трея | 330 по ширине, высота по содержимому до 560 |

## Иконки

Один набор геометрий 24 × 24 в `Themes/Icons.xaml`, все рисуются **обводкой** — так набор
выглядит одинаково в любом размере и перекрашивается одной кистью. Шрифты-иконки не используются.

Обводка `Path` привязана к унаследованному `TextElement.Foreground`, поэтому иконка внутри
кнопки автоматически перекрашивается вместе с ней при наведении.

Иконки приложения и трея генерируются из той же геометрии — `tools/make_icons.py`.
Трей меняет цвет по состоянию: серая перечёркнутая (адаптер выключен), светлая (включён,
подключений нет), охристая (есть подключения).

## Движение

- Наведение и нажатие — 120–130 мс, `CubicEase EaseOut`.
- Поповер трея — 140 мс, проявление.
- Полоса поиска — заполнение слева направо за 1.1 с, затем затухание.
- Никаких bounce и elastic.

## Тени

Тень только там, где элемент действительно висит над другим: поповер трея и диалог
сопряжения. Карточки внутри окна плоские — поверхность плюс граница.
