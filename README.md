# Bluetooth Manager Pro

Менеджер Bluetooth-устройств для Windows 10 и 11 — быстрее и удобнее штатного.
Минималистичный тёмный интерфейс с охристым акцентом, живёт в трее и всегда под рукой.

<sub>Один `.exe`, ноль зависимостей NuGet, работает без прав администратора.</sub>

---

## Зачем, если есть настройки Windows

Чтобы отключить наушники в Windows 11, нужно: открыть «Параметры» → «Bluetooth и устройства»
→ найти устройство → «…» → «Отключить». Четыре–пять действий и полсекунды ожидания на каждое.

Здесь то же самое — один клик из трея.

| | Параметры Windows | Bluetooth Manager Pro |
|---|---|---|
| Подключить / отключить устройство | 4–5 действий | **1 клик** (из трея — не открывая окно) |
| Список спаренных и найденных рядом | на разных экранах | **один список** |
| Заряд батареи устройств | разбросан по карточкам | **в общем списке** |
| Избранные устройства | нет | **звёздочка → трей** |
| Вкл/выкл адаптера | 2 действия | **тумблер в трее** |
| Дубликаты BR/EDR + LE одного устройства | показываются дважды | **склеены в одну строку** |

## Возможности

**Устройства**
- Единый живой список: подключённые, сопряжённые и найденные поблизости — с группировкой.
- Подключение и отключение одним кликом, включая классические аудиоустройства
  (Windows не даёт для этого WinRT API — используется `BluetoothSetServiceState`).
- Сопряжение с новыми устройствами: все четыре сценария подтверждения
  (просто подтвердить, показать PIN, ввести PIN, сверить коды) — со своим диалогом в теме приложения.
- Удаление сопряжения. Убираются **обе** конечные точки устройства (BR/EDR и LE),
  иначе устройство возвращается в список.
- Заряд батареи и уровень сигнала там, где Windows их сообщает.
- Иконка по типу устройства: наушники, колонка, мышь, клавиатура, геймпад, часы, телефон.

**Трей и запуск**
- Сворачивается в трей; иконка меняется в зависимости от состояния
  (выключен / включён / есть подключения).
- Меню в трее — избранные и подключённые устройства, тумблер Bluetooth, быстрые ссылки.
- Автозапуск с Windows, при желании сразу в трей.
- Один экземпляр: повторный запуск разворачивает уже работающий.

**Быстрый доступ**
- Прямые ссылки на страницы Windows: Bluetooth, звук, громкость приложений,
  принтеры, режим «в самолёте», автозагрузка, «Устройства и принтеры», диспетчер устройств.

## Установка

Готового бинарника пока нет — собирается одной командой.
Требуется Windows 10 версии 2004 (сборка 19041) или новее и **64-разрядная** система.

```powershell
git clone https://github.com/s-erlish/bt-manager-pro.git
cd bt-manager-pro
.\build.ps1 -SelfContained
```

Готовый файл: `publish\win-x64\BluetoothManagerPro.exe`. Его можно положить куда угодно
и запустить — установка не требуется. Настройки хранятся в
`%LOCALAPPDATA%\BluetoothManagerPro\settings.json`.

Подробности сборки — в [docs/BUILD.md](docs/BUILD.md).

> При первом запуске SmartScreen может предупредить о неизвестном издателе: файл не подписан
> сертификатом. «Подробнее» → «Выполнить в любом случае».

## Что честно не работает

Тут нет магии — есть ограничения самой Windows, и лучше знать о них заранее.

- **Заряд батареи виден не у всех устройств.** Windows получает его только от гарнитур,
  которые сами сообщают уровень по HFP, и от LE-устройств со стандартным сервисом батареи.
  Для остальных показывать нечего — и приложение не рисует выдуманное значение.
- **Уровень сигнала есть только у Bluetooth LE и только пока устройство рекламируется.**
  У подключённых классических наушников RSSI недоступен в принципе.
- **Устройства Bluetooth LE нельзя «отключить» кнопкой.** Windows подключает их по требованию,
  когда приложение открывает сессию GATT; управляемого разрыва там нет.
- **Отключение классических устройств** выполняется через отключение их профилей
  (`BluetoothSetServiceState`) — это же делают «Параметры» Windows. На отдельных стеках
  сторонних адаптеров может не сработать; тогда приложение честно скажет об этом и предложит
  открыть системные настройки.
- **Поиск новых устройств длится 30 секунд и запускается только по кнопке.**
  Постоянный inquiry забивает эфир 2,4 ГГц и вызывает заикания у подключённых наушников.

## Технически

- .NET 8 + WPF, `net8.0-windows10.0.19041.0`, unpackaged, обязательно x64.
- Ноль зависимостей NuGet — только то, что даёт SDK.
- WinRT (`Windows.Devices.Enumeration`, `Windows.Devices.Bluetooth`, `Windows.Devices.Radios`)
  для обнаружения, сопряжения и управления адаптером.
- Win32 (`bthprops.cpl`) для подключения/отключения и реального состояния классических устройств.
- Трей — `System.Windows.Forms.NotifyIcon` (сам восстанавливается после перезапуска explorer.exe),
  меню — собственное WPF-окно, чтобы соответствовать теме.
